# BuildMediaStrategies Website

The public website for BuildMediaStrategies, a digital product and marketing business based in Kent, UK.

## Project overview

A multi-page React website presenting web development, SEO and automation services. The site is structured around service discovery, relevant industries, local landing pages and contact/conversion pathways.

## My contribution

- Built and maintained the React application and reusable page structure.
- Developed service, industry, portfolio and location-specific pages.
- Improved conversion-focused copy and on-page SEO.
- Worked on metadata, sitemap, mobile presentation and performance configuration.
- Iterated on the site based on business goals and implementation feedback.

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Supabase client library
- Lighthouse CI configuration

## Local development

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run lint
npm run build
```

The repository includes a Lighthouse CI configuration and image-optimisation scripts. These checks should be run in the target environment before treating a particular build as verified.

## Notes

This is the source for a business website, not a standalone SaaS product. Integrations and environment-specific services may require local environment variables. Never commit credentials or production secrets.
